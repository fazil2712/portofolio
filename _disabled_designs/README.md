# Preserved & Disabled Portfolio Designs

This directory contains preserved versions of alternative portfolio designs and the comparison hub developed for Muhammad Fazil Ataurrahman.

> **Active Portfolio:** Design C (Fieldnotes) is deployed at the repository root (`/`).

---

## Catalog of Preserved Designs

### 1. `original/`
- **Concept:** Dark Space / Particle Canvas / Glassmorphism
- **Key Features:** Canvas-based interactive particle network, glowing gradient cards, full modal popups, EN/ID language switcher.
- **Tech / Fonts:** Outfit, Inter, JetBrains Mono.

### 2. `portfolio-a/` (Meridian)
- **Concept:** Editorial Print / Sunday Magazine
- **Key Features:** Warm ivory (`#F5F0E8`) & terracotta (`#C4622D`), subtle SVG paper grain texture, newspaper-column layout, serif typography.
- **Tech / Fonts:** Playfair Display, Source Serif 4, Space Mono.

### 3. `portfolio-b/` (Prism)
- **Concept:** Geometric Mosaic / Bento Grid
- **Key Features:** Dark navy (`#0D1117`), electric violet (`#7C3AED`) and neon lime (`#A3E635`), floating abstract geometric polygon accents, responsive bento grid structure.
- **Tech / Fonts:** Space Grotesk, DM Sans, JetBrains Mono.

### 4. `portfolio-c-backup/`
- **Concept:** Technical Field Notes (Original Standalone Version)
- **Note:** This is the standalone subdirectory version of Design C before it was promoted to the repository root.

### 5. `portfolio-hub/`
- **Concept:** Portfolio Comparison Studio & Switcher
- **Key Features:** Live scaled iframe previews of all 4 designs side by side, 2×2 grid mode, stacked row mode, single-design focus mode, and fullscreen lightbox preview.

---

## Restoring or Testing Any Design Locally
To preview any preserved design locally, open its `index.html` in your browser.
Note that relative image paths inside screenshots refer to `../../assets/screenshots/` or `../assets/screenshots/`.
