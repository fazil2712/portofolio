# Muhammad Fazil Ataurrahman — Portfolio

Official personal portfolio website of **Muhammad Fazil Ataurrahman** (Informatics undergraduate at Telkom University Bandung).

Built with semantic HTML5, modern token-driven CSS, and vanilla JavaScript — completely static with **no build step required**.

- **Active Design:** **Design C (Fieldnotes)** — technical field notes aesthetic with ruled lines, tabular project directory, inline expanders, and bilingual (EN/ID) support.
- **Live Deployment:** [https://fazil2712.github.io/portofolio/](https://fazil2712.github.io/portofolio/)

---

## 📁 Repository Structure

```
portfolio/
├── index.html                 # Official portfolio (Design C: Fieldnotes)
├── style.css                  # Design tokens & styling
├── script.js                  # Projects data, typewriter, and language switcher
├── 404.html                   # Branded fallback page
├── assets/
│   └── screenshots/           # Project screenshots (PPIP, SuperKos, Tata AI, etc.)
├── _disabled_designs/         # Preserved alternative designs (not deleted)
│   ├── original/              # Original particle canvas portfolio
│   ├── portfolio-a/           # Design A: Meridian (Editorial print)
│   ├── portfolio-b/           # Design B: Prism (Geometric bento)
│   ├── portfolio-c-backup/    # Original Design C standalone version
│   ├── portfolio-hub/         # Multi-design preview & comparison switcher
│   └── README.md              # Documentation of archived designs
└── README.md
```
